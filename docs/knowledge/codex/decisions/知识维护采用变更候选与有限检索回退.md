# 知识维护采用变更候选与有限检索回退

本项目通过开发任务中的 agent 按需收录和维护知识。Git 差异和笔记来源关系用于找出需要核对的候选；是否修订、废止或保留为历史，由 agent 结合当前实现与已确认要求判断。

此前验证发现，索引刷新不会自动修正旧知识，中文全文查询也可能漏召回。因此先补变更检查和限定知识目录的字面检索回退，继续沿用官方读写技能与既有 Git 审查。具体命令、检查范围及未覆盖事项以 docs/project-knowledge.md 为准。

## Observations

- [decision] 先跑通当前项目的收录、变更维护和后续读取，再考虑跨项目复用。
- [constraint] 文档合并不代表方案批准；历史 checkpoint 保留当时状态。
- [consequence] 候选检查依赖正确的来源关联和 Git 基点，不能宣称全库知识已经自动保持最新。
